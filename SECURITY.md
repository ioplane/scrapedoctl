# Security Policy

## Supported Versions

Only the latest fixed version of `scrapedoctl` is supported for security
updates.

| Version  | Supported |
| -------- | --------- |
| 0.2.1    | :x:       |
| <= 0.2.0 | :x:       |

Published version `v0.2.1` is affected by `SEC-001` and should not be used with
an active API token. The planned fixed version is `v0.2.2`, which is not yet
released. See the
[security patch release checklist](docs/en/06-security-patch-release.md).

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it
by opening an issue or contacting the maintainers directly.

We take all security reports seriously and will work to resolve the issue as
quickly as possible.
